**第 0 期发现：**
- 家长端 H5 的构建产物把接口地址写死为线上域名（`mini-program/.env.production`）。冒烟测试会在浏览器里拦下所有发往线上域名的请求，转给本地临时后端，并检查「没有请求发到本机以外的地址」。
- 基线数据（320px 宽）：8 个页面全部有小于 12px 的文字，最少 3 处、最多 28 处，最小 10.0px。375px 宽时，有 4 个页面各有 1 处 11.8px 的文字；414px 宽时没有问题。
- 在截图上确认了以下问题：H5 顶部多出一条空白（U-10）、「请假」标签是橙字配浅蓝底（U-7）、老师姓名后面没有「老师」（U-16，留到第 2 期处理）。

**第 1 期改动：**
- **字号下限：** `tokens.scss` 新增 `p-fs()`。32rpx 及以下的字号在窄屏上不再缩小，至少等于设计稿（375 宽）上的像素值；375px 及以上的屏幕和原来完全一样。家长端 32rpx 以下的字号已全部改用 `p-fs()`。孩子头像里的字也设了 12px 下限。
- **字重：** 650 和 700 统一为 600（苹方最粗只到 600）。
- **对比度：**
  - 次要文字 ink-3 从 `#64748B` 改为 `#5B6577`：在页面底色上 5.4:1，原来是 4.37。
  - 原来用 ink-4（2.4:1）写的文字改用 ink-3。
  - 红色标签文字改用 `$p-rose-ink`（5.9:1）。
  - 课表选中日期上的星期改为 90% 白（4.7:1→5.1:1；原来 60% 白只有 3.1）。
  - 登录框占位文字改为 `#6B7280`（4.6:1）。
- **请假标签：** 删除指错颜色的 `$p-peach` 别名，新增 `$p-status-leave-*` 和 `$p-status-absent-*`，请假一律用琥珀色。
- **登录页：** 「清空」和「显示密码」图标外面包了一层 88rpx 的按钮（图标本身不接收点击），教职工登录也一起修了；20 和 22rpx 的小字提到 24rpx。手机号输入框仍是 `type=number`（小程序不支持 `tel`），留到以后。
- **H5 顶部：** 状态栏高度和右侧胶囊留白只在小程序上计算，H5 上为 0。
- **点击区域：**
  - 新增 `p-hit-min`；`p-hit-area` 改为以元素中心向外撑开，并加 44px 下限（88rpx 在 320px 宽时只有 37.5px）。
  - 返回、孩子切换、展开、照片/视频切换、关闭视频、设备「退出」、「本周」都用上了。
  - 底部标签格的高度不小于 44px。
- **无障碍：**
  - 25 个可点击元素加了 `role="button"` 和 `tabindex`。
  - 只有图标的按钮加了 `aria-label`（返回、上一周、下一周、关闭视频、清空、显示密码）。
  - 键盘操作时显示焦点框。
  - 星级旁边默认显示分数，并加了读屏说明。
- **检查脚本 `lint:ui`：**
  - 字号检查覆盖登录页、`p-fs()` 和 px 写法。
  - 新增 `parentFontWithoutFloor`（32rpx 及以下的字号必须用 `p-fs()`，上限 0）。
  - 新增 `parentHexColors`（家长端写死的颜色，当前 58 处，只能减少，第 3 期降到 0）。
- **验收：**
  - 冒烟测试 09 默认硬性检查：320、375、414 三种宽度 × 8 个页面，所有文字 ≥ 12px，可点击区域两边 ≥ 24px 且面积 ≥ 44×44。75 项全部通过。
  - 唯一例外：课表一周 7 天的日期格在 320px 宽时只能做到 36×56px，面积达标，按面积判定为合格。

## Context
家长端是学校对家长的「门面」，用户大多在手机上看，其中不少是年纪偏大的家长。
现有设计的底子不错：
- 页面结构清楚，有课评、课表、课程、成长、我的五个栏目；
- 有一套 tokens 和统一的空状态；
- 骨架屏、缩略图懒加载、视频海报都已经做了。

问题集中在四个方面：
1. **可读性和无障碍**：小屏上字号低于 12px；多处对比度不达标。手机上禁止双指缩放这一点保持现状，所以字号和对比度更要做好。
2. **设计体系没有约束住**：14 种字号、约 20 种圆角，约 80 处写死颜色。
3. **出错时像「没有数据」**：所有页面在网络出错时都显示「还没有…」，没有重试按钮。
4. **信息前后对不上**：列表卡片上说有的照片、视频和评分，详情页里不显示。

这份计划书的目标：
- 让家长看得清、点得准；
- 出了问题知道发生了什么、可以重试；
- 各页面看起来是同一个产品；
- 每一条都可以验收。

**范围约束：**
- 员工小程序本周期不改。家长端和员工小程序共用的文件（`pages/login`、`App.vue`、`utils/request.ts`、`components/AppIcon.vue`）只做不影响员工端的改动，并在小程序上回归测试。

## 三、设计规格（第 1 期落地，写进 `package-parent/styles/tokens.scss` 并附文档）
